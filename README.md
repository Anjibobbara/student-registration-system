# 🎓 Student Registration System

A full-stack Student Registration System built using:

- HTML5
- CSS3
- JavaScript
- Node.js
- MongoDB Atlas
- Mongoose
- Vercel Serverless Functions

## Features

- Register Student
- View Students
- Update Student
- Delete Student
- Search Students
- Responsive Design
- MongoDB Database
- Serverless Deployment

## Project Structure

```
Student-Registration-System
│
├── api
├── config
├── models
├── public
├── package.json
├── vercel.json
├── .env
└── README.md
```

## Installation

```bash
npm install
```

## Run

```bash
vercel dev
```

## Deployment

Deploy easily on Vercel.
